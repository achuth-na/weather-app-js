# 🌦️ Weather App

A responsive weather application that provides real-time weather information for any city using the OpenWeather API.

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Real-time temperature
- ☁️ Weather condition
- 💧 Humidity
- 🌬️ Wind speed
- 📱 Responsive design

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- OpenWeather API
